## Шаг 2.
Присвоить нужным пользователям новые роли.
## Шаг 3.
Заполнить значения констант “Токен управления телеграм-ботом”, “Идентификатор группы для оповещения”, “Номенклатура абонентская плата”, “Номенклатура работы специалиста”, расположенных на вкладке “Обслуживание клиентов” раздел “Сервис”.
## Шаг 4.
Добавить необходимую информацию о договорах абонентского обслуживания контрагентов, указав в карточке договора вид договора “Абонентское обслуживание” и заполнив необходимую информацию об условиях договора (срок действия и стоимость).
## Шаг 5.
Добавить информацию об окладах и процентах от выполненных работ, установленные для сотрудников. Для этого используется новый регистр сведений “Условия оплаты сотрудников”.
